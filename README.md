# 课程超市

面向学校选课的静态网页。六层场馆包含 12 个学科专柜；本版有 612 门课程，其中整套课程 268 门、课例做法 344 个。可按楼层、学科、学段、规格和关键词浏览，将课程放入购物车、记录本校想法、组合融合课程，再生成可打印的回执。

正式网址：<https://supermarket.qiustudio.cn>。EdgeOne Makers 的 `supermarket` 项目已关联此仓库的 `main` 分支，生产环境开启自动部署。GitHub Pages 是备份。

## 本版来源

2026-09-24，用户指定 `课程超市-html.zip` 为本次上线的最新版，明确要求采用压缩包中的课程名单与文字。原压缩包 SHA-256：`ca0c1bd1527abc9fb33822b55887e25bc45ab0e43e0d3b6dfcb265294e165d74`。设计工具导出的页面已整理为根目录 `index.html`，原课程数据独立为 `assets/design-catalog.js`；样式补充在 `assets/design-responsive.css`。

本版与上一版公开货架的名单及文案有差异，不能将两版课程编号直接视为同一内容。

## 使用与数据

网页在浏览器本机生成回执，没有服务器订单接口，也不会发送表单中的学校、联系人或电话。购物车、课程想法和融合课程保存在本机浏览器存储中；学校、联系人和电话不写入本机存储。换设备或清除浏览器数据后，记录不会自动同步。旧版书篮不自动迁移到本版。

本地预览：在仓库目录启动静态文件服务器，然后打开 `index.html`。仅打开 `file://` 文件可能导致运行脚本受浏览器限制。
