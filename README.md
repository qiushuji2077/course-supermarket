# 课程超市

面向进校沟通的静态选课网页。页面以“课程超市”为真实交互隐喻：问题索引是导购台，12 个学科是 12 组货架，每组固定 5 层货栏；课程可以放入手推车，也可以放回货架，最后生成小票式选课流水单。

页面只发布匿名化后的课程方向与主要做法，不包含来源名称、内部管理信息或评分。

## 更新内容

在课程资源库根目录运行：

```bash
ruby "80 展示输出/课程超市/generate.rb"
```

生成器会重新读取课程卡，只发布当前可对外展示的课程，并保留既有课程编号。

## 本地预览

用任意静态文件服务器打开本目录即可；也可以直接打开 `index.html`。选课记录保存在当前浏览器中，刷新页面不会丢失。

## 隐私边界

- 不发布来源名称、源文件路径与内部评分字段。
- 外部素材只保留“外部参考”标记，不发布来源主体名称。
- 内部编号映射保存在网站目录之外，不进入公开仓库。
