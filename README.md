# 课程超市

面向学校选课的静态网页。页面以“课程超市”为真实交互隐喻：问题索引是导购台，12 个学科是 12 组货架，每组固定 5 层货栏；课程可以放入手推车，也可以放回货架，最后生成小票式选课流水单。

页面以内部工作底账的原文展示课程名、副名、一句话与主要做法。底账没有副名就留空，不编。仅对校名做匿名处理，不展示来源校名或评价信息。归档页不上架。

现网：<https://supermarket.qiustudio.cn>（腾讯云 EdgeOne Pages）。GitHub Pages 只当备份。

## 更新内容

不要直推 `main`。生成数据后开分支，用 Pull Request 合并。`main` 一合并后以 EdgeOne 域名核对货架。

源是白话写回、质检判「通过」的「课程超市内部工作底账」工作底账页，不是 8 月 19 日课程资源数据库，不是外部案例表，不是旧课程卡直推。

在本机对底账运行生成器（`generate.rb` 读工作底账；该文件留在主库，不要提交到 GitHub）：

```bash
ruby "80 展示输出/课程超市/generate.rb"
```

生成器只发布工作底账页课程，保留既有课程编号，副名为空则空着。

然后开分支、提交 `assets/courses.js`、创建 PR。协作说明见 [CONTRIBUTING.md](CONTRIBUTING.md) 和 [AGENTS.md](AGENTS.md)。

## 本地预览

用任意静态文件服务器打开本目录即可；也可以直接打开 `index.html`。选课记录保存在当前浏览器中，刷新页面不会丢失。

## 展示边界

- 只展示课程编号、学段、学科、主题、课程名、副名、一句话和做法要点。
- 不展示任何来源主体、源文件路径或评价信息。
- 不对一句话、做法要点做摘要、改写或补写。

## 主屏幕

Safari 打开现网后「添加到主屏幕」，作为 PWA 使用。每次打开会网络优先拉取 `index.html` 和货架数据；离线才用上次缓存。

主屏幕上的图标画面有时会留着旧图。要换成新印章，删掉旧图标再添加一次。货架内容仍会在打开时更新。
