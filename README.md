# 课程超市

面向学校选课的静态网页。六层场馆包含 12 个学科专柜；本版有638条学生课程案例：保留原始612条摘要，新增26项教学推演摘要。本次27项课程（含1项同主题扩展）可查看分步建议，另有11项教师研修或对象待核实的实践参考，不计入学生货架。原标“整套课程”的268条保留来源分类，不表示资源已经齐备。可按楼层、学科、学段、规格和关键词浏览，将课程放入购物车、记录本校想法、组合融合课程，再生成可打印的回执。

正式网址：<https://supermarket.qiustudio.cn>。EdgeOne Makers 的 `supermarket` 项目已关联此仓库的 `main` 分支，生产环境开启自动部署。GitHub Pages 是备份。

本版与上一版公开货架的名单及文案有差异，不能将两版课程编号直接视为同一内容。

## 使用与数据

网页在浏览器本机生成回执，没有服务器订单接口，也不会发送表单中的学校、联系人或电话。购物车、课程想法和融合课程保存在本机浏览器存储中；学校、联系人和电话不写入本机存储。换设备或清除浏览器数据后，记录不会自动同步。地址栏的 `#cart`、`#checkout`、`#course=编号` 只记录当前步骤或所看课程，可用浏览器“返回”逐步退回，也可复制课程链接给同事；课程链接不含学校信息；“复制回执文字”会把回执内容（含所填学校信息）复制到本机剪贴板，不会发送给任何人。旧版书篮不自动迁移到本版。

本地预览：在仓库目录启动静态文件服务器，然后打开 `index.html`。仅打开 `file://` 文件可能导致运行脚本受浏览器限制。

## 2026-11-20 年级、课时与材料建议层

原始 612 条里有 162 条的适用年级只写“小学”或“初中”。`assets/suggestion-catalog.js` 为这 162 条各补一组建议年级、建议课时和建议材料，页面上以“建议 · 未经原校确认”标出：卡片上是虚线框的“建议：……”，课程详情里是单独的建议区块。

- 这些建议仅依据本站已公开的课程名称、简介与做法推断，未经原校确认，也未经试教，不是来源学校的实际安排。
- `assets/design-catalog.js` 没有任何改动；卡片、详情和回执里的“适用年级”仍显示原文。
- 搜索可以命中建议年级（例如“四年级”）；回执和复制的回执文字不包含建议内容。
- 需要整体移除时，删除 `assets/suggestion-catalog.js` 及 `index.html`、`sw.js` 中对它的引用即可，页面在文件缺失时照常运行。
- 如果之后拿到原校资料，按资料改写对应条目，并在该条目上去掉“建议”的说法前先取得用户确认。
